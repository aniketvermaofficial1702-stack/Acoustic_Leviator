PUBLISH WITH GITHUB PAGES:
1. Sign in to GitHub and create a new public repository (for example: acoustic-levitation).
2. Upload all three HTML files from this folder to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish.

Your public links will follow this format:
https://YOUR-USERNAME.github.io/acoustic-levitation/
https://YOUR-USERNAME.github.io/acoustic-levitation/pitch-presentation.html
https://YOUR-USERNAME.github.io/acoustic-levitation/3d-lab-unit.html

Note: Replace YOUR-USERNAME with your GitHub username. The pages are prepared here, but they are not publicly hosted until you complete the GitHub Pages publishing steps.
